<h1>Notas antes de usar el aplicativo:</h1>
<br>
1. El proyecto se conecta a la base de datos mediante el puerto 3306<br>
2. El nombre de la base de datos debe ser si o si "db_paya" de lo contrario no funcionara el aplicativo<br>
3. El proyecto debe ser ejecutado en una version moderna de netbeans ejemplo la version IDE30 para arriba de lo contrario generara errores
